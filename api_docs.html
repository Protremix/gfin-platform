API Documentation

Public and law enforcement API endpoints for GFIN

Overview

The GFIN API provides access to fraud reporting, scam checking, analytics, and law enforcement tools. Public endpoints require no authentication. Police endpoints require JWT authentication.

Base URL: https://gfin-system.com

🔒 Victim Portal API No Auth

/api/victim/register
/api/victim/login
/api/victim/me
/api/victim/complaint
/api/victim/complaints
/api/victim/complaint/{ref}
/api/victim/track/{ref}
Track complaint status by reference number (no auth required)

🔍 Scam Database API Public

/api/scam-sites/check/{domain}
Check if a domain is in the scam database
/api/scam-sites/list
List known scam websites (paginated)
/api/scam-sites/search
Search scam database by keyword
/api/scam-sites/stats
Get scam database statistics (counts, risk levels, losses)

📊 Analytics API Public

/api/analytics/overview
Total complaints, active cases, losses, wallets traced
/api/analytics/scam-types
Breakdown by scam category (15 types)
/api/analytics/risk-levels
Distribution by risk level (critical, high, medium, low)
/api/analytics/countries
Cases by country
/api/analytics/timeline
Complaints over time
/api/analytics/financial-loss
Financial loss breakdown
/api/analytics/crypto
Cryptocurrency tracing statistics

🛡️ Scam Detection API Public

/api/scam-detect
Analyze text for scam indicators using deterministic v3.0 engine (300+ patterns, 15 categories)

🌍 Country Routing API Public

/api/countries
List all 189 supported countries with cybercrime contacts
/api/countries/{country_code}
Get routing details for a specific country (contacts, Interpol, Europol)
/api/countries/search/{name}
Search countries by name

🔍 Intelligence Playbook API Public

/api/playbook/investigate
Run full intelligence investigation from trigger to physical address
/api/playbook/entities
List supported entity types for investigation

📢 Awareness & Telegram API Public

/api/awareness/stats
Awareness broadcast statistics
/api/awareness/types
List 12 scam awareness types
/api/telegram/status
Telegram bot status and subscriber count
/api/telegram/subscribers
Get Telegram subscriber count (anonymized)

👮 Police API Auth Required

/api/police/login
Police officer login (returns JWT, 7-day expiry)
/api/police/me
Get current officer profile
/api/police/register
Register new officer (admin only — first registration auto-admin)
/api/police/officers
List all officers (admin only)
/api/awareness/broadcast
Broadcast awareness message to all Telegram subscribers (police only)
/api/awareness/broadcast/{scam_type}
Broadcast specific scam type awareness (police only)

📋 Reports API Auth Required

/api/reports/generate
Generate investigation report for a case
/api/reports/download/{filename}
Download generated report file

🔐 Evidence API Auth Required

/api/evidence-secure/{case_id}
Secure evidence retrieval with chain of custody

System

/health
Health check — returns server status and database connection state
/robots.txt
SEO robots file
/sitemap.xml
XML sitemap for search engines

Rate Limits

  • General API: 100 requests/minute
  • Authentication endpoints: 10 requests/minute
  • Police endpoints: 60 requests/minute per IP
  • Complaint filing: 5 per hour per victim
