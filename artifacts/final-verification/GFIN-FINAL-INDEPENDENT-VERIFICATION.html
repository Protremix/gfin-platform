4. What Failed

  • Credential security (FAIL): DB password 'GfinSecure2026!' hardcoded in 2 Python files. Admin password in git history.
  • Case/tenant isolation (FAIL): RLS NOT enabled on any table. Any authenticated user sees all cases, evidence, and victims.
  • Evidence integrity (FAIL): Only 1 of 171 evidence items has a content hash. No tamper detection, no chain of custody, no hash verification.
  • False positive rate (NOT TESTED): No ground-truth benchmark run. Cannot claim reliability without this.
  • Adversarial data (NOT TESTED): No mechanism to reject false correlations, classify wallet ownership, or handle contradictions.
  • 6 of 19 providers broken: SEC EDGAR, Tronscan, GDELT, ICIJ, Solscan, XRPL return 404/timeout
